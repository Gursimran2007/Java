## Running any program

Every file is a self-contained class with its own `main`, so no build tool is
needed — Java 11+ can run a single source file directly:

```bash
java Sem3/Week1/Practice/RockPaperScissorsGame.java
```

Or compile and run the classic way:

```bash
javac RockPaperScissorsGame.java && java RockPaperScissorsGame
```
